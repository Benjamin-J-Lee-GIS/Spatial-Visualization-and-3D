# Spatial Visualization & 3D Modeling Portfolio

A collection of cartographic layouts, 3D terrain visualizations, and structural models demonstrating design standards and spatial geometry workflows.

## Featured Work
1. **Academic Cartographic Layouts:** Formal map layouts emphasizing scale, projection selection, typography, and visual hierarchy built in QGIS and ArcGIS Pro.
2. **3D Terrain Renders:** Digital Elevation Models (DEMs) processed into realistic 3D spatial meshes using Blender.
3. **CAD & Spatial Structures:** Structural models and site geometries designed using Fusion 360.

### Software Stack
* **GIS:** QGIS, ArcGIS Pro
* **3D & CAD:** Blender, Fusion 360
